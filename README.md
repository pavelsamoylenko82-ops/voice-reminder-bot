# Voice-Enabled Telegram Reminder Bot 🎙️

A voice-first Telegram bot designed for seamless task scheduling and asynchronous notification delivery.

## ⚡ Core Features
- **Voice Input Processing:** Transcribes and parses voice messages into actionable scheduled reminders.
- **Async Task Scheduling:** Reliable background job execution for timely notifications.
- **Production-Ready Deployment:** Fully containerized architecture running on a VPS.

## 🛠 Tech Stack
- **Backend:** Python 3.11, aiogram 3.x
- **Infrastructure:** Docker, Docker Compose, Linux VPS
